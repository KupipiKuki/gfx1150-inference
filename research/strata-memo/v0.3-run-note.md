## Output failure

`mistral-output.md` is 33,767 characters but only 62 words:

- 33,338 characters are spaces; the longest single run is **33,264 spaces**.
- After the `### Criteria table` header the model emitted the whitespace run
  until it hit the 2,200-token cap.
- The only usable content is the recommendation: **Hybrid-A** (which agrees
  with the auditor's D, hybrid), and two sentences of justification.

This is a greedy-decoding degeneration triggered by the wide 5-column table
with long cells. It is a model/prompt failure, not an engine failure.

## Fix for the v0.2 run

The revised `prompt.txt`:

- removes the wide table and asks for a bulleted criteria comparison;
- explicitly forbids table padding, long whitespace runs and repeated tokens;
- orders the recommendation and decisive reasons first, so a later
  degeneration cannot hide the conclusion;
- caps the memo at 1,200 words.

Run command:

