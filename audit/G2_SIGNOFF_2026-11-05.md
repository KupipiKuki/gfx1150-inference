## 1. Why G2 is held

The four former xfails are closed and all 23 7A-3 goldens pass, but the
SentencePiece path does not reproduce llama.cpp on ordinary text or around
special tokens. Two blockers are recorded in
`audit/AUDIT_7B_TOKENIZER_DEEP_2026-11-05.md`:

- **BLOCKER-7B-1:** SPM special-token chunks omit the reference dummy `▁`
  prefix before and after a special token.
  - `a<s>b`: reference `[261, 1, 268]`, candidate `[412, 1, 430]`.
  - `hi<s>there`: reference `[270, 417, 1, 383]`, candidate
    `[415, 417, 1, 413, 260, 276]`.
- **BLOCKER-7B-2:** the SPM segmentation is Viterbi; the pinned reference is
  a score-priority greedy bigram merge. They disagree on common words.
  - `the`: reference `[265]`, candidate `[259, 260]`.
  - `and`: reference `[269]`, candidate `[261, 264]`.
  - `time`: reference `[378]`, candidate `[259, 369]`.
  - 14/39 common words and 7,529/20,000 synthetic piece concatenations
    differ; the reference binary reproduces all 11 SPM goldens.

The reference used is the same pinned `llama.cpp@149f5641…` that produced the
7A-3 goldens; a binary built from that commit matches all 11 SPM golden
vectors exactly.

  CPU 128, GPU 24, `test_cpu_only` 12/12 both modes, claims checker PASS.

- `add_bos` precedence and the GPT-2 golden vectors are accepted as tested.
- Byte-safety probes: no silent loss; lone surrogate and missing bytes raise
  `ValueError`.

1. Fix the SPM fragment prefix to mirror the reference’s `is_prev_special`
   (prefix every raw fragment that starts the input or follows a special

2. Implement the reference score-priority greedy merge for SPM, or obtain an
   explicit auditor/owner scope decision to use canonical Viterbi and narrow
   the README/ledger reference claims accordingly. The default is to match
   the reference.
3. Add SPM mixed-text and differential golden vectors generated with the
   pinned `llama-tokenize` (not hand-written to match the candidate).
4. Guard the `_is_normal_piece` short-`token_types` `IndexError` (QF-1).
5. QAQC re-runs the differential probes, then the primary audit re-reviews.
