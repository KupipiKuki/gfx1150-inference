## 3. Findings

### QAQC-7D-1 — ❌ open (Low): negative `block_count` with zero `blk.*` tensors is accepted
- **File:** `src/weight_loader.py:98-115` (`_cross_check_block_count`)
- **Repro (captured in `qaqc-probes/qaqc-run.log`, EDGE-1):** `llama.block_count = -1` (INT32)
  with no `blk.*` tensors → `found == [] == list(range(-1))` → no error, `WeightStreamer.num_layers = -1`.
  With real tensors it is rejected (EDGE-2). Huge dims are rejected at parse (EDGE-3).
- **Fix for the coder:** after `declared_count = int(declared)`, add
  `if declared_count < 0: raise ValueError(f"Invalid {arch}.block_count {declared_count}: must be >= 0")`;
  add a test in `tests/test_memory_residency.py` (INT32 `-1`, zero blk tensors → ValueError).

### QAQC-7D-2 — ◐ scope note (Info): `src/layer.py` touched although not in brief §2's allowed list
- **File:** `src/layer.py:9-11` — docstring-only change (eviction wording). No behavior change
  (`git diff` shows only the module docstring). Either accept as docs-adjacent or revert the hunk.

### QAQC-7D-3 — ◐ needs auditor adjudication (Medium): `MADV_DONTNEED` used as a PTE-drop enabler whenever `MADV_PAGEOUT` is absent
- **File:** `src/weight_loader.py:340-400` (`_evict_spans`)
- Brief §7D-1's letter says `MADV_DONTNEED` may be kept only as a warned last-resort fallback when
  *neither* fadvise nor PAGEOUT exists. The coder instead issues it (PAGEOUT when present, else
  DONTNEED) **before every fadvise** so the hint can act. Empirically necessary on this host:
  fadvise alone is inert for live mappings (probe: RSS unchanged after fadvise-only; majflt>0
  only after PTE drop + fadvise). Docs never present DONTNEED as page-cache eviction (README L125,
  PLAN L79/L17, ledger row 21), and the no-channel case still warns once. Recommend accepting
  with the documented wording; if the letter of the brief is enforced, the alternative is
  fadvise-only STREAM, which on this host evicts nothing (evidence in `red.log`/`notes.md`).
