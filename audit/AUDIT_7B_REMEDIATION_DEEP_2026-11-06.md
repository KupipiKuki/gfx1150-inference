## 2. Blockers closed

### BLOCKER-7B-1 — SPM prefix around special tokens

`_split_special_tokens` now returns `(chunk, special_id)` runs, and `encode()`
drives them with the reference’s `is_prev_special` state:

- start `prev_special = True`;
- a raw fragment gets the leading space/`▁` when `prev_special`, then clears it;
- a special fragment emits its ID and sets `prev_special = True`.

The chunk-offset bookkeeping that caused the leading-chunk bug is gone.

### BLOCKER-7B-2 — SPM segmentation algorithm

The Viterbi path and `_UNK_PENALTY` are removed. `_encode_spiece` normalizes
the fragment and `_spm_segment` runs `_greedy_merge_symbols`:

- split the normalized text into UTF-8 characters;
- seed every adjacent pair whose concatenation is a token;
- merge max score first, ties leftmost (the reference `llm_bigram_spm`
  comparator);
- surviving non-token symbols emit `<0xXX>` byte tokens or raise `ValueError`
  naming the byte (7B-4 preserved).

`_greedy_merge_symbols` is shared with BPE and uses merge ranks only when
ranks exist (the BPE path), scores otherwise (the SPM path). The 12 GPT-2
goldens remain green.
