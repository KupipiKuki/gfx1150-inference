Two real bugs were found by the drills and fixed with regressions:

- **D2:** runner 2.338.2 checks the local `.runner`/`.credentials` before
  `--replace`; a server-side deletion left the local config, so
  `config.sh --replace` refused. Fix `c4a82a6` removes the stale local config
  first; agent 23 → 24 recovered. (`d2-incident-2026-11-15.txt`)
- **D5:** on a restart the runner writes a config log and a listener log ~1 s
  apart; a closest-timestamp tie selected the config log, producing a false
  `NOT_LISTENING` and an unnecessary repair. Fix `192bdb8` prefers a file
  at/after the service start. (`d5-incident-2026-11-15.txt`)

The sdist initially shipped the new tests without their fixtures
(`scripts/ci/*`, `.github/workflows/ci-gpu.yml`); fix `582ff05` ships them and
makes the `ci-cpu.yml` content assertion require them. The PR's sdist lane is
green.
